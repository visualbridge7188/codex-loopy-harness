# harness-report Skill

Compiles status metrics from evaluations to render overall readiness reports.

## Evaluation Dimensions
- **D1: Pipeline Completeness** (Init, Team, QA, Self-Improve links)
- **D2: Cross-Phase Integration** (Data flows between stages)
- **D3: Hook Enforcement Depth** (Fail-closed exit code blocks)
- **D4: Self-Improvement Velocity** (Speed of rule extraction)
- **D5: Convergence Maturity** (Stability of the learning rate)
