# /dashboard

Opens the local browser dashboard to visualize multi-agent status, 36 HARD check progress, and 5-dimension report scores.

## Usage

```bash
/dashboard
```

## Details
Launches the web UI from `docs/graph-3d.html` or `docs/knowledge-graph.html` containing interactive node charts representing task connections and memory bank facts.
