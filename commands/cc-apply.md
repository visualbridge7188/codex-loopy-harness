# /cc-apply

Triggers the apply script to deploy the harness configuration template to the local Claude Code user scope.

## Usage

```bash
/cc-apply
```

## Description
Copies all settings, specialist definitions, rules, and hook scripts from the workspace directory to the active user scope (`~/.claude/`), and applies execution permissions to all script files.
