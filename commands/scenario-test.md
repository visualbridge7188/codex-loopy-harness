# /scenario-test

Runs automated E2E interaction test scenarios on the current web application.

## Usage

```bash
/scenario-test
/scenario-test --spec <file>
```

## Details
Invokes the local Playwright E2E browser automation suite to click buttons, verify navigation routes, test form submissions, and inspect pages for rendering anomalies.
